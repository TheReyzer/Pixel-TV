# Pixel animal profile pack

## Expanded production pack — 2026-10-22

There are now **24 different species**. The original twelve sprites below remain in their original order and retain their saved profile IDs. A second transparent 1448×1086 atlas, `../app/src/main/res/drawable-nodpi/avatar_animals_pixel_extra.png`, adds elephant, raccoon, otter, owl / frog, penguin, duck, cow / horse, giraffe, zebra and capybara. It was generated with the built-in image_gen tool using the original atlas as a style reference. Both atlases live in the project and decode lazily at half resolution (about 3 MiB combined).

All views use the same renderer: it trims transparent margins within each isolated sprite, preserves aspect ratio and centers the complete visible head both horizontally and vertically, with equal opposing margins. Tall ears/horns remain inside the portrait. No bitmap smoothing is applied. The 24 background colors are drawn by the app. The fixed Save button uses the common neutral theme with white focus, matching the Discovery wizard; the chosen color changes only the avatar preview. The single color row scrolls horizontally with the remote.

## Original atlas

Created with the built-in image_gen tool on 2026-10-22. The requested “164bits” was interpreted as a 16-bit retro pixel-art aesthetic, not an encoded bit-depth requirement.

The production atlas is `../app/src/main/res/drawable-nodpi/avatar_animals_pixel.png` (1448×1086 RGBA). Its twelve portraits are cat, dog, fox, panda, koala, tiger, bear, wolf, monkey, rabbit, pig and lion. Each species appears once. Source rectangles in `ProfileController.PIXEL_HEAD_BOUNDS` isolate complete heads, including long ears; runtime drawing preserves aspect ratio and uses nearest-neighbor scaling. Color backgrounds are drawn by the launcher. The atlas is decoded once at half resolution, about 1.5 MiB, and released with the controller.
