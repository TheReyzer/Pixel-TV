# Segurança

Use somente TVs e computadores sob sua autorização. Ative ADB em rede apenas em uma rede confiável, confira a autorização do computador e revogue o acesso quando não precisar mais.

O instalador exige um dispositivo explícito, valida a configuração, guarda backup e conserva o launcher original. Acessibilidade, notificações e localização são opcionais e precisam ser compreendidas antes de habilitar.

HTTPS usa a validação padrão de certificados/hostname. Corrija relógio, rede ou certificados do sistema quando houver erro; não desligue validação TLS. Não publique credenciais, cookies, dados pessoais ou chaves em issues.

Para relatar vulnerabilidade, use o contato privado do mantenedor ou o relato privado do GitHub quando habilitado. O dono do repositório precisa configurar esse canal; não há endereço de contato inventado no template.

Antes de publicar, gere e revise a exportação limpa. O histórico de uma cópia de trabalho pode conter dados antigos mesmo depois de removê-los dos arquivos atuais; a exportação não copia .git.
